# Handoff: сценарий «Код с радара», слой 0 (скелет без угроз)

Контекст для исполнителя: Unity, C#, сетевая часть на **Mirror**, логика **server-authoritative**. Кооп на двоих: **водитель** (в машине) и **напарник** (на платформе грузовика).
Грузовики в мировых координатах стоят на месте, движение изображается прокруткой дороги (`MotionDirector`). Значит, положение машины относительно грузовика — это просто её мировое положение.

Полный дизайн: `design/scenario-code.md`. Этот документ — только слой 0.

## Что уже есть в проекте (сначала найди и переиспользуй)
- Вождение машины, включая рывок (dash).
- Крюк-кошка, стрельба.
- Двери и хранилище, открываемые карточкой.
- Перенос лута.
- Респавн при касании земли (мгновенный, на точке спавна).
- Система взаимодействия игрока с объектами (если есть).

**Перед реализацией** изучи эти системы и опиши в ответе, что переиспользуешь, а что придётся добавить. Имена классов ниже — предложения, подстраивайся под существующие соглашения проекта.

## Цикл слоя 0

1. Водитель подвозит напарника, тот забирается на платформу (уже работает через крюк или прыжок).
2. Водитель встаёт в зону стоянки у борта грузовика → начинается расшифровка кода.
3. Символы расшифровываются по одному. Каждый новый символ видит только водитель на своём HUD и диктует его голосом (голос внешний, например Discord, в игре его делать не нужно).
4. Напарник вводит символы на консоли **по мере расшифровки**.
5. После последнего символа открывается короткое окно ввода.
6. Код введён верно → хранилище открывается.
7. Напарник бросает награду в машину, затем прыгает в машину сам.
8. Награда в машине и оба игрока в машине → рейд завершён.

## Фичи

### F1. Зона стоянки (`DecryptParkingZone`)
- Trigger-объём у борта грузовика + опорная точка (anchor).
- Условие «стоянка активна» (проверяет сервер каждый тик):
  - в машине есть водитель;
  - машина внутри зоны;
  - смещение машины от anchor ≤ `parkingTolerance`;
  - машина сейчас не в рывке (и не раньше чем через `dashCooldownBlock` секунд после рывка).
- Если условие нарушено, расшифровка **на паузе**: прогресс текущего символа сохраняется, но не растёт.

**Параметры:** `parkingTolerance` [2 м], `dashCooldownBlock` [1 с].

### F2. Логика кода (`CodeVaultController`, только сервер)
Состояния: `Idle → Decrypting ⇄ Paused → InputWindow → Solved`.
- При старте генерируется код из `codeLength` цифр (0–9).
- `Decrypting`: каждые `symbolDecryptTime` секунд активной стоянки раскрывается следующий символ. `revealedCount` синхронизируется.
- После раскрытия последнего символа → `InputWindow` на `inputWindowTime` секунд.
- Флаг `rotateCodeOnWindowExpire` (**по умолчанию false**, для слоя 3): окно истекло, код не введён → новый код, введённое стирается, расшифровка с нуля. При false окно — просто таймер на HUD.
- Код верный и полный → `Solved` → событие открытия хранилища.

**Параметры:** `codeLength` [5], `symbolDecryptTime` [4 с], `inputWindowTime` [5 с].

### F3. HUD водителя (`DriverCodeHUD`)
- Показывается только тому, кто сейчас сидит за рулём.
- Отображает:
  - раскрытые символы и заглушки для нераскрытых (`3 7 _ _ _`);
  - прогресс текущего символа;
  - статус: «Расшифровка» / «ПАУЗА: вернись в зону» / «Окно ввода: N с» / «Открыто»;
  - сколько символов напарник уже ввёл (чтобы водитель знал, что диктовать дальше).
- Защита от читов не нужна (кооп): можно синхронизировать код всем, а скрывать только на уровне UI.

### F4. Консоль-кейпад (`CodeConsole`)
- **Кнопки в мире** (0–9), нажимаются через существующую систему взаимодействия. Никакого модального UI, который блокирует управление: напарник в любой момент может отвернуться и стрелять.
- Экран консоли в мире показывает введённые символы (видно обоим игрокам).
- Ввод отправляется командой на сервер (в Mirror: `[Command(requiresAuthority = false)]` с `NetworkConnectionToClient sender`).
- Правила на сервере:
  - если введено уже столько символов, сколько раскрыто, нажатие **игнорируется** (обратная связь — звук или вспышка «ещё не расшифровано»). Это защищает от перебора нераскрытых позиций;
  - символ не совпадает с `code[enteredCount]` → **весь введённый код стирается**, обратная связь об ошибке;
  - совпадает → добавляется к введённому.

### F5. Открытие хранилища по коду
- Подключить `Solved` из F2 к существующему механизму открытия хранилища или двери (сейчас он работает от карточки). Добавить код как ещё один источник открытия, не ломая карточку.

### F6. Бросок награды в машину
- Если в переносе лута уже есть бросок — переиспользовать. Если нет — добавить бросок переносимого предмета по физической дуге (сила на кнопку).
- В машине **зона кузова** (trigger): предмет лута, попавший в неё, считается погруженным и прикрепляется к машине (kinematic, parent или attach).
- Предмет промахнулся и упал на дорогу → через `lootReturnDelay` секунд возвращается в хранилище (временная заглушка для прототипа).
- Физика на сервере. Полноценная сетевая физика лута — отдельная задача, здесь достаточно минимума.

**Параметры:** `lootReturnDelay` [3 с].

### F7. Посадка напарника в машину
- Проверь, есть ли у машины пассажирское место или состояние пассажира. Если нет — минимальная версия: trigger над машиной; напарник, попавший в него в прыжке, переходит в состояние «пассажир» (позиция закреплена за машиной, камера следует за машиной).
- Промахнулся → существующий респавн при касании земли (окно спасения будет позже, отдельно).
- Нужно и обратное действие: выйти из машины и забраться на платформу, чтобы напарника можно было высадить в начале.

### F8. Завершение рейда
- Условие: хранилище открыто, лут в кузове, оба игрока в машине → событие `RaidCompleted`.
- Для прототипа достаточно надписи «Рейд завершён» обоим и лога.

## Отладка
- Все параметры доступны в инспекторе.
- Дебаг-оверлей (для хоста): состояние F2, `revealedCount`, `enteredCount`, активна ли стоянка и почему нет.
- Чит-клавиши: мгновенно раскрыть все символы, ввести код верно.

## Критерии приёмки (проверить на host + client)
1. Машина в зоне, без рывка → символы раскрываются по одному, HUD видит только водитель.
2. Выехать за порог или сделать рывок → «ПАУЗА», прогресс символа сохраняется; вернуться в зону → расшифровка продолжается.
3. Напарник может ввести только уже раскрытые символы; лишние нажатия игнорируются с обратной связью.
4. Неверный символ стирает весь ввод; повторный верный ввод проходит.
5. Полный верный код открывает хранилище; карточка по-прежнему работает там, где использовалась.
6. Брошенный в кузов лут закрепляется за машиной; промах возвращает лут в хранилище.
7. Напарник может спрыгнуть в машину и выйти из неё; промах → обычный респавн.
8. Лут в кузове + оба в машине → «Рейд завершён» у обоих.
9. С `rotateCodeOnWindowExpire = true` по истечении окна код меняется и ввод стирается.

## Вне слоя 0 (не делать)
Враги, урон машине, окно спасения при падении, поворотный пулемёт, радар как отдельная механика (сейчас это HUD), встроенный голосовой чат.
